Chorus Gather Hub

Application Overview

This document outlines the comprehensive features implemented in the Chorus Gather Hub. The system provides role-based access control with specialized functionality for both administrative users and standard users, enabling efficient monitoring and management of temperature-sensitive beacon devices.

Table of Contents

  • 1. User Role Management
  • 2. Device Scanning & Monitoring
  • 3. Device Details & Analytics
  • 4. Administrative Configuration

1. User Role Management

Choose Roles Screen

The application provides role-based access control with two distinct user types:

  • Admin User Access
    • Device configuration facility for administrative users
    • Authentication required for secure access
    • Full system privileges including device settings management
  • Standard User Access
    • Direct access to Gather Hub for non-administrative users
    • Streamlined interface focused on monitoring capabilities
    • No authentication barriers for quick device monitoring

2. Device Scanning & Monitoring

Scan Screen - Main Dashboard

The central hub for device discovery and status monitoring with comprehensive filtering capabilities:

  • Device Discovery
    • Automatic detection of all devices in vicinity
    • Real-time display of device status and metrics
  • Device Information Display
    • MAC ID - Unique device identifier
    • Status - Alert, Normal, or (---)
    • Temperature - Current temperature readings
  • Search & Filter Capabilities
    • Manual search input for filtering devices by MAC ID
    • QR code scanning functionality for rapid device identification
    • Scan button integration for beacon QR code reading
  • Temperature Alert System
    • Automatic status determination based on temperature thresholds
    • Alert State: Temperature > 8°C or < 2°C
    • Visual indicators for normal vs. excursion states
  • Interactive Controls
    • Connect button for devices in alert/excursion state
    • Configuration icon for device settings (Admin users only)
Configuration icons are exclusively available to authenticated admin users for security and system integrity.

3. Device Details & Analytics

Comprehensive Device Information Screen

Detailed device analytics and historical data visualization:

  • Core Device Metrics
    • MAC ID - Device identification
    • Battery Level - Current power status
    • Firmware Version - Software version information
    • Current Temperature - Real-time temperature reading
  • Excursion Event Analysis
    • Excursion Event Timestamp - Most recent temperature violation
    • Excursion Detection: Temperature > 8°C or < 2°C
    • Excursion Duration - Time elapsed from event to current time
  • Data Visualization
    • Interactive temperature vs. time graph
    • Visual representation of temperature fluctuations over time
  • Data Export Functionality
    • Complete historical data export in CSV format

4. Administrative Configuration

Device Settings Screen

This screen is exclusively accessible to authenticated admin users only.
  • Current Configuration Display
    • Real-time temperature threshold configuration view
    • Current firmware version information
    • System status overview
  • Temperature Threshold Management
    • Dynamic temperature threshold updating
    • Real-time configuration changes
  • Firmware Management
    • Firmware version upgrade functionality
