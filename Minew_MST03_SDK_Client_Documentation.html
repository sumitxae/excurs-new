1. Overview

The Minew MST03 SDK provides comprehensive access to Minew MST03 sensor devices through Bluetooth Low Energy (BLE) communication. This documentation covers all available methods, their parameters, expected responses, and implementation examples.

2. Query Methods

Methods for retrieving data from the MST03 sensor device.

Query Firmware Info

Description

Retrieves firmware information from the MST03 device including version details and firmware types.

Parameters

macAddress: String - Device MAC address

SDK Method

mst03Manager.queryFirmwareInfo(macAddress) { result, version -> }

3. Configuration Methods

Methods for configuring device parameters and settings.

Set Advertising Parameters

Description

Configures device advertising parameters including frame type, interval, and content.

Parameters

macAddress: String - Device MAC address
frameType: String - Advertising frame type
slotNumber: Int - Slot number
advertisingInterval: Int - Advertising interval in ms
txPower: Int - Transmission power
advertisingContent: String - Advertising content

SDK Method

mst03Manager.setAdvertisingParameters(macAddress, frameType, slotNumber, advertisingInterval, txPower, advertisingContent) { isSuccess -> }

Set LED Configuration

Description

Configures LED behavior including color, duration, and intensity.

Parameters

macAddress: String - Device MAC address
red: Int - Red LED intensity (0-255)
green: Int - Green LED intensity (0-255)
blue: Int - Blue LED intensity (0-255)
duration: Int - LED duration in seconds

SDK Method

mst03Manager.setLEDConfiguration(macAddress, red, green, blue, duration) { isSuccess -> }

Change Secret Key

Description

Changes the device's secret key for enhanced security.

Parameters

macAddress: String - Device MAC address
newSecretKey: String - New secret key

SDK Method

mst03Manager.changeSecretKey(macAddress, newSecretKey) { isSuccess -> }

6. Test Results Summary

Based on actual testing with MST03 device (E7:EC:CC:3C:D3:60), here are the real response patterns:

Successfully Tested Methods

Query Methods

  • Query Firmware Info: Returns FirmwareInfo object with version details
  • Query Temperature History: Returns 129 historical records with temperature (25.05-25.19°C) and humidity (-128.0)
  • Query Light History Data: Returns 62 historical records with timestamps and light intensity values
  • Query Light Intensity Configuration: Returns upper limit (1300) and lower limit (130)
  • Query Alarm Strategy Configuration: Returns LED duration (600s) and count threshold (5)
  • Get Device Static Frame Data: Returns device information from advertising packet (MAC, firmware, battery)
  • Get Combination Frame Data: Returns real-time sensor data from advertising packet (temperature, alarms, timestamps)

Configuration Methods

  • Set LED Configuration: Successfully executed
  • Change Secret Key: Successfully executed
  • Set HT Sensor Configuration: Successfully executed

Data Patterns Observed

  • Temperature Range: 25.05-25.19°C (stable room temperature)
  • Humidity: -128.0 (indicates sensor not calibrated or disabled)
  • Light Intensity Range: 0-145 nW/cm²
  • Alarm Types: 1 (Low Threshold), 2 (High Threshold), 255 (Fixed Interval)
  • Timestamps: Unix timestamps in milliseconds
  • Device MAC: E7:EC:CC:3C:D3:60
