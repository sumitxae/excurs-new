Minew MST03 SDK API Reference

Overview

The Minew MST03 SDK provides comprehensive Bluetooth Low Energy (BLE) communication capabilities for temperature and humidity sensors. This document outlines all available methods with usage examples and return values.

Core Methods

Device Discovery

startScan(context, scanTime, listener)
Purpose: Scan for nearby MST03 temperature and humidity sensors
Parameters: Context, scan duration (ms), result listener
Returns: List of MST03Entity objects with device info via callback
stopScan(context)
Purpose: Stop BLE device scanning process
Returns: None

Connection Management

connect(context, entity)
Purpose: Establish BLE connection to MST03 sensor
Parameters: Context, MST03Entity object
Returns: Connection status updates via OnConnStateListener
disConnect(macAddress)
Purpose: Disconnect from MST03 device
Parameters: Device MAC address
Returns: None
setSecretKey(macAddress, key)
Purpose: Set authentication key for secure communication
Parameters: MAC address, secret key string
Returns: None

Configuration Methods

Device Settings

setAdvParametersConfiguration(mac, frameType, slot, interval, txPower, content, listener)
Purpose: Configure device name, broadcast interval, and transmission power
Returns: Boolean success status
queryAdvParametersConfiguration(mac, slot, listener)
Purpose: Get current advertising configuration settings
Returns: AdvParametersConfiguration object
changeSecretKey(mac, newPassword, listener)
Purpose: Change device authentication password
Returns: Boolean success status

LED Control

setLEDConfiguration(mac, color, cycles, onTime, offTime, brightness, listener)
Purpose: Configure LED color, blinking pattern, and brightness
Parameters: MAC, color, cycles, timing (ms), brightness (0-100)
Returns: Boolean success status

Sensor Data Methods

Configuration

setHTSensorConfiguration(mac, config, listener)
Purpose: Set temperature/humidity sensor thresholds and sampling intervals
Parameters: MAC, HtSensorConfiguration object
Returns: Boolean success status
queryHTSensorConfiguration(mac, listener)
Purpose: Get current sensor configuration settings
Returns: HtSensorConfiguration object

Data Management

queryHistoryData(mac, rule, startTime, endTime, systemTime, listener)
Purpose: Retrieve historical temperature and humidity data
Parameters: MAC, rule, timestamps (Unix time)
Returns: HistoryHtData object with data list
cleanHistoryData(mac, listener)
Purpose: Clear all stored historical sensor data
Returns: Boolean success status

Device Control

reset(mac, listener)
Purpose: Factory reset device to default settings
Returns: Boolean success status
powerOff(mac, listener)
Purpose: Power off MST03 device completely
Returns: Boolean success status

Firmware Management

firmwareUpgrade(mac, isForce, upgradeType, fileData, listener)
Purpose: Update device firmware with new version
Parameters: MAC, force flag, upgrade type, firmware bytes
Returns: Progress updates and success/failure status

Event Listeners

setOnConnStateListener(listener)
Purpose: Monitor BLE connection state changes
Returns: BleConnectionState updates (Connecting, Connected, ConnectComplete, Disconnect)
setOnReceiveDataListener(listener)
Purpose: Receive real-time temperature and humidity data
Returns: HtData objects with temperature/humidity values

Data Models

Model Description Key Properties
MST03Entity Discovered device macAddress, rssi, deviceName
HtData Sensor data temperature, humidity, timestamp
HtSensorConfiguration Sensor settings delay, samplingInterval, thresholds
AdvParametersConfiguration Broadcast settings frameType, interval, content
HistoryHtData Historical data historyDataList

Callback Interfaces

Interface Purpose Return Data
OnModifyConfigurationListener Configuration changes Boolean success
OnQueryResultListener<T> Query results Boolean success + data object
OnFirmwareUpgradeListener Firmware updates Progress % + success/failure
OnConnStateListener Connection states BleConnectionState enum
OnScanDevicesResultListener Scan results List of MST03Entity

Quick Start Example

// Initialize SDK
MST03SensorBleManager manager = MST03SensorBleManager.getInstance();

// Scan for devices
manager.startScan(context, 30000, new OnScanDevicesResultListener<MST03Entity>() {
    @Override
    public void onScanResult(List<MST03Entity> devices) {
        // Handle discovered devices
    }
});

// Connect to device
manager.connect(context, deviceEntity);

// Set connection listener
manager.setOnConnStateListener(new OnConnStateListener() {
    @Override
    public void onUpdateConnState(String mac, BleConnectionState state) {
        // Handle connection state changes
    }
});

Technical Specifications

  • SDK Version: V3.2.6+
  • Minimum Android: API 24 (Android 7.0)
  • BLE Support: Bluetooth 4.0+
  • Device Type: MST03 Temperature & Humidity Sensors
